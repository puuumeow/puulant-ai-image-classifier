# Puulant – AI Image Classifier

An experimental mobile image classification application developed using MIT App Inventor.

## Overview

Puulant is a mobile application prototype exploring the integration of image classification capabilities into Android applications.

The project uses camera functionality and an image classification component to explore how images can be processed and classified through a mobile interface.

## Features

- Camera integration
- Image input and processing
- Image classification component integration
- Prediction result display
- Mobile user interface

## Technologies Used

- MIT App Inventor
- PersonalImageClassifier component
- Camera component
- Visual programming with blocks
